# Tamboer AI

Gecontroleerde AI-workflows voor terugkerend werk in administratie, klantcontact, offertes en marketing bij Nederlandse mkb-bedrijven.

Bij Tamboer AI doet AI het voorwerk en controleert en beslist een medewerker. We bouwen op de software waar bedrijven al dagelijks mee werken, zonder onnodige nieuwe lagen of losse chatbots.

## Technische stack

- **AI-modellen en omgevingen:** Claude, ChatGPT, Microsoft 365 Copilot
- **Ontwikkeling en runtime:** Python, TypeScript, Cloudflare Workers, Cloudflare Pages, Cloudflare D1
- **Automatisering en koppelingen:** n8n, Make, Power Automate, REST API's en webhooks
- **Mkb-bedrijfssoftware:** Microsoft 365, Outlook, Gmail, SharePoint, Exact Online, AFAS, Moneybird

## Hoe we bouwen

Elke workflow volgt vijf vaste controles voordat er iets live gaat:

1. **Input:** welke bronnen zijn toegestaan en hoe valideren we invoer.
2. **Autoriteit:** wat de workflow mag voorbereiden en wat hij nooit zelfstandig mag doen.
3. **Goedkeuring:** waar een medewerker controleert en vrijgeeft.
4. **Uitzondering:** wanneer de route stopt bij ontbrekende of tegenstrijdige gegevens.
5. **Bewijs:** logging zodat achteraf aantoonbaar is wat er gebeurde.
